# Referansebaselines

ZIP-filene kopieres ikke inn i releasepakken. `BASELINES.json` låser SHA-256 for de eksplisitte funksjonelle/designmessige referansene som fortsatt har verdi. Historisk p19-dokumentasjon distribueres ikke i p23 fordi den beskriver en forlatt teknisk arkitektur og kan forveksles med gjeldende løsning. Gjeldende arkitektursperrer og forlatte løsninger dokumenteres som aktive beslutninger i `docs/14-AKTIVE-BESLUTNINGER.md`.
